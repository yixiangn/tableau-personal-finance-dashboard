# Tableau Personal Finance Dashboard

This project uses synthetic personal finance transaction data to build an interactive Tableau dashboard.

The goal is to practise data visualization, dashboard design, financial trend analysis, and basic data preparation using a safe, generic dataset.

## Project Objectives

- Generate a clean synthetic transaction dataset
- Build Tableau dashboards for income, expenses, savings, and spending categories
- Practise calculated fields, filters, KPI cards, and dashboard layout
- Document the dashboard-building process clearly

## Dataset

The main dataset is `data/transactions.csv`.

It contains generic personal finance transactions with fields such as:

- transaction date
- transaction type
- account name
- category
- subcategory
- merchant
- amount
- signed amount
- payment method
- status
- recurring flag
- budget category

## Dashboard Pages

Planned dashboard sections:

1. Financial Overview
2. Income Analysis
3. Expense Analysis
4. Category Breakdown
5. Transaction Details
